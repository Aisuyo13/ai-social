# AI Social — Мини-социальная сеть

Полноценный pet-проект социальной сети, разработанный с нуля. Включает в себя авторизацию, профиль, посты, диалоги, темы оформления и адаптивный дизайн.

## 🚀 Возможности

- 🔐 Аутентификация и авторизация (логин, logout, session)
- 👤 Профиль пользователя (с аватаром, именем, редактированием)
- 📝 Создание и отображение постов (CRUD)
- 💬 Диалоги и список друзей
- 🌗 Светлая и тёмная темы (Tailwind + Context)
- 📱 Полностью адаптивный дизайн
- 🎨 Стили на Tailwind CSS с кастомными утилитами
- 📦 Хранилище данных на JSON (имитация API)
- ⚡ State management через Redux Toolkit + React Context
- 🔄 Подгрузка моковых данных
- ✅ Написано на TypeScript

---

## 🛠️ Стек технологий

| Категория     | Технологии                                  |
|---------------|----------------------------------------------|
| Фреймворк     | React 19 + TypeScript                        |
| Стили         | Tailwind CSS + кастомные переменные          |
| Управление состоянием | Redux Toolkit, React Context         |
| Роутинг       | React Router DOM v7                          |
| Формы         | React Hook Form                              |
| Мок-сервер    | JSON-файлы с мок-данными                     |
| Backend (в будущем) | Django + PostgreSQL (планируется)      |
